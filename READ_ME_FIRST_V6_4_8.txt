NUNES COMPANY PLATFORM V6.4.8
================================

FIRST TIME ON THE SERVER PC
1. Extract the complete ZIP to a permanent folder.
2. Double-click SETUP_THIS_PC_AS_SERVER.bat.
3. Choose Yes when Windows asks for Administrator permission.
4. Wait for OPEN_ON_OTHER_DEVICES.txt to open.

ON ANOTHER OFFICE DEVICE
1. Connect the phone/computer to the same Wi-Fi or wired office network.
2. Open the Other devices URL shown in OPEN_ON_OTHER_DEVICES.txt.
3. Do not use localhost or 127.0.0.1 on another device.

EVERYDAY USE
- NUNES starts automatically after the server-PC user signs in.
- Keep the server PC turned on.
- OPEN_SERVER_LINK.bat opens the app and current sharing link again.
- CHECK_OTHER_DEVICE_ACCESS.bat checks the server and prints the correct link.

VERCEL LINK
The Vercel site can display live PC-held data only through a public HTTPS data
backend. For normal office use, use the Other devices link generated here.

OLD DATA
Existing Purchasing and Servicing records are not reset or replaced.
