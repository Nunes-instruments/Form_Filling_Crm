NUNES V6.6.4 - GEMINI DEFAULT LOCAL SECRET

Purpose
- Automatically apply the owner-provided Gemini API key on the Main Server PC.
- No manual key paste is required.
- Gemini model is set to gemini-3.6-flash.

Security design
- The bootstrap key exists only under LOCAL_ONLY_SECRETS in this delivery ZIP.
- LOCAL_ONLY_SECRETS is ignored by Git and blocked by the NUNES Git staging safety check.
- After successful setup, K_APPLY_DEFAULT_GEMINI_V6_6_4.bat deletes the plaintext bootstrap file from the extracted folder.
- The active key remains in persistent ServiceData and a Windows-user DPAPI encrypted fallback under LOCALAPPDATA.
- Future code/runtime rebuilds keep the key without staff setup.

Run
1. Extract the ZIP on the Main Server PC.
2. Right-click K_APPLY_DEFAULT_GEMINI_V6_6_4.bat -> Run as administrator.
3. Wait for Live Test : OK.
4. Open Servicing and use Read & Fill Form.
5. Staff PCs only Refresh / Ctrl+R.
