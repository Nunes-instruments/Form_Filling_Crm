NUNES V6.6.0 - SIMPLE GITHUB SINGLE SOURCE
==========================================

USE ONLY THESE FILES FOR NORMAL SETUP/UPDATES:

1) 0_NUNES_ALL_IN_ONE_SETUP.bat
   Run this on EVERY PC and choose its role:
   MAIN SERVER / OWNER / STAFF.

2) 1_PUSH_GITHUB_AND_GO_LIVE.bat
   Use on the MAIN SERVER / development folder after VS Code changes.
   It applies the code live, commits safely, and pushes to GitHub main.

3) 2_CHECK_GITHUB_AUTO_UPDATE.bat
   Use on MAIN SERVER to confirm server + GitHub auto-pull status.

ARCHITECTURE
------------
GitHub main
   -> MAIN SERVER automatically checks every 1 minute
   -> new commit is fast-forwarded, built, verified, and applied
   -> owner/staff open the SAME main-server web app from their Desktop icon
   -> already-open pages detect the new rollout and refresh themselves

OWNER/STAFF PCs DO NOT KEEP A COPY OF THE APPLICATION SOURCE.
This is intentional: there is nothing to copy/update on 10 staff PCs.
Their permanent Desktop icon always opens the latest version served by MAIN SERVER.
