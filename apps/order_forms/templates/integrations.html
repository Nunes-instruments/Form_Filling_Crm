Google Drive / Sheets Integration

Completed records can update a master Google Sheet and upload final PDF/XLSX files to Drive.

Required Google setup: enable Google Sheets API and Google Drive API in the Google Cloud project, create a service account, download its JSON key, and share the target Sheet/Drive folder with the service-account email. If credentials are not configured, the app keeps working and records remain Pending Sync.
