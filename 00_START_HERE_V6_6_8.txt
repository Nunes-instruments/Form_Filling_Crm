NUNES OPERATIONS V6.6.8
=======================

WHY THIS VERSION EXISTS
-----------------------
V6.6.7 could fail during Main Dashboard compilation with:
  Module not found ... AppData\Local\NUNES Operations\PlatformCache\runtime\...\node_modules\next\dist\client\components\builtin\global-not-found.js

ROOT CAUSE
----------
The old dashboard installer used a Windows junction from:
  platform_web\node_modules
into:
  %LOCALAPPDATA%\NUNES Operations\PlatformCache\runtime\...

Next.js 15 / webpack can resolve that junction to its external real path while compiling.
For a deeply nested Desktop release folder, the generated ../../../../AppData path can be wrong.
The packages can exist and still fail to resolve during build.

V6.6.8 FIX
----------
- node_modules is now a NORMAL PHYSICAL folder inside platform_web during build.
- The old AppData node_modules junction is automatically removed.
- npm's download cache remains reusable, so package downloads can still be warm.
- The exact Next.js locked version is verified.
- global-not-found.js is verified before build.
- One automatic clean reinstall/retry is retained.
- Existing V6.6.7 WhatsApp Easy Connect behavior and dashboard UI are preserved.
- Purchasing / Servicing / Gmail / Gemini / WhatsApp persistent data are not intentionally deleted.
